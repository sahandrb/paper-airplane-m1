# Asset attribution

The images in this project are AI-generated images made for the Paper Airplane Flight Lab. They are not photographs of a real aircraft, field, or launcher.

Sahand Ranjbaripour commissioned them for this project.

## Runtime images

- `assets/aircraft/paper_dart.png` — paper dart, nose pointing right, transparent background. 949 by 249 pixels.
- `assets/background/dusk_field.jpg` — dusk sky and dark ground. 1280 by 720 pixels.
- `assets/launcher/catapult.png` — rubber-band catapult. 330 by 279 pixels.

## Preview

- `docs/images/scene_preview.jpg` — composed preview of the dusk field, launcher, and dart. 1280 by 720 pixels. This is a visual reference, not a runtime atlas.
